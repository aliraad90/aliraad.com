=== SLIDE 4: METADATA STRUCTURE ===
1. Title: "Document Metadata Structure"
2. Create a table with 4 columns:
   - Field Name | Type | Options/Format | Purpose
3. Add 7 rows:
   Row 1: Plant Name | Dropdown | Kharblaa/Najaf/Al-Kharkh | Identify source plant
   Row 2: Document Type | Choice | Engineering/QA-QC/Operations/Contracts/Maintenance | Categorize document
   Row 3: Revision Number | Text | Rev 01, Rev 02, etc. | Version control
   Row 4: Status | Choice | Draft/Under Review/Approved/Archived | Track approval status
   Row 5: Owner | Person | SharePoint user | Responsible person
   Row 6: Date Issued | Date | DD/MM/YYYY | Track creation date
   Row 7: Project Code | Text | Plant-specific codes | Link to project
4. Header row: Purple background (#5E2584), white text
5. Alternate row colors: white and light grey (#F8F9FA)

=== DESIGN TIPS ===
1. Use rounded rectangles for all boxes
2. Add subtle shadows (2-4pt offset)
3. Keep consistent spacing between elements
4. Use icons from Microsoft 365 built-in icons
5. Maintain consistent alignment
6. Use gradient fills for main boxes (purple and blue)
