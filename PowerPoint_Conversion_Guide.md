# SharePoint Document Control System - PowerPoint Conversion Guide

## Overview
This guide helps you convert the HTML presentation into a professional PowerPoint presentation for your SharePoint Document Control System covering Kharblaa, Najaf, and Al-Kharkh power plants.

## Method 1: Direct HTML to PowerPoint (Recommended)

### Step 1: Open the HTML File
1. Open the `SharePoint_Document_Control_Presentation.html` file in your web browser
2. The presentation will display with professional formatting and Siemens Energy colors

### Step 2: Print to PDF (Optional)
1. Press `Ctrl+P` (or `Cmd+P` on Mac)
2. Select "Save as PDF" as the destination
3. This creates a PDF version you can reference

### Step 3: Screenshot Method for PowerPoint
1. Take screenshots of each slide section from the HTML presentation
2. Insert these as images into PowerPoint slides
3. Add text boxes over the images for editable content

## PowerPoint Design Tips

### 1. Master Slide Setup
- Create a master slide with Siemens Energy colors
- Add consistent header/footer elements
- Set up standard text styles

### 2. Shape Creation
- Use rounded rectangles for cards and boxes
- Apply gradient fills where specified
- Add subtle shadows for depth (2-4pt offset)

### 3. Icons and Graphics
- Use Microsoft 365 built-in icons
- Search for: cloud, document, workflow, security, dashboard
- Maintain consistent icon size (24-32pt)

### 4. Animation (Optional)
- Add subtle entrance animations
- Use "Fade In" or "Fly In From Left"
- Keep timing consistent (0.5-1 second)
